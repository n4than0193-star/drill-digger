*About Drill Digger*
Drill Digger is a down-scrolling, arcade-style game where you play as a drill trying to dig as deep as possible, while avoiding hazards like rocks
and staying hydrated with water pools. It is loosely inspired by some faint memory of a game similar to it from my childhood. It is my *SECOND*
game ever, and a bit more complex than my first game.

*How to play Drill Digger*
To play my glorious creation, head to this link: https://n4th4ni3l.itch.io/drill-digger   
and press Run Game. Enjoy!
